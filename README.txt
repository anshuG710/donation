DONATE+ Nepal Design Frontend

This is the redesigned frontend-only prototype based on the uploaded visual reference. It adapts the reference into an original DONATE+ design focused on Nepal and item donation.

Pages included:
index.html, login.html, register.html, donor-dashboard.html, add-donation.html, my-donations.html (not included in this design pass), recipient-dashboard.html, find-donations.html, donation-details.html, request-donation.html, admin-dashboard.html.

Tailwind is not used as a build dependency here; the UI uses the same utility-style approach with a small custom stylesheet so it can open immediately. Later we can convert the styling to your required Tailwind CSS setup if needed.

Images use remote Unsplash URLs for prototype visuals. Internet is required to display them.

Next stage: convert these static pages to PHP, create MySQL database/tables, connect PHP to MySQL, then implement authentication, sessions, CRUD, uploads and approval workflow.
